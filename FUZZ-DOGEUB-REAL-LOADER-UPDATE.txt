FuzzTheHuzz + DogeUB real game loader integration

This update replaces the custom Doge game handling with DogeUB's actual
local-game loader model.

Important behavior:
- Doge entries with local=true use Doge's ZIP -> JSZip -> IndexedDB ->
  loadersw.js -> /game/<name>/index.html flow.
- Doge entries with local=false are NOT downloaded as ZIP files. They are
  opened through Fuzz's existing proxy engine, matching Doge's own behavior.
- Doge icon paths under /assets/img and /assets-fb are rewritten to DogeUB's
  actual asset CDN, so the real artwork can load.
- The Doge game service worker is scoped to /game/ so it cannot intercept
  Fuzz Home, Apps, AI, Cloud, Admin, or proxy pages.
- Local games open inside Fuzz's existing /p shell and use its existing
  full-screen behavior.

No DogeUB proxy, ads, navigation, settings, homepage, React UI, or branding
are copied.
