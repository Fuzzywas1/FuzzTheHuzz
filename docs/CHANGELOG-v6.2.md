# Fuzz 6.2 — Unified Settings

## Fixed

- The Admin item is now visible only to the `owner` role, matching the server-protected `/admin` route.
- The `Ctrl + Shift + O` Admin shortcut no longer works for non-owner accounts.
- Clicking Settings while already on the Account page now switches to Preferences immediately.
- `/c` and `/settings` now open the unified Settings area.

## Restored

- Synced account preferences
- Search-engine and proxy defaults
- Fuzz AI response style
- Announcements, reduced motion, and proxy-history controls
- About:blank behavior and panic keys
- Tab cloak and local background URL
- Local interface effects and browser-settings import/export

## Added to Settings

- PNG, JPEG, and WebP wallpaper upload
- External wallpaper URL
- Fit, position, blur, and dark overlay
- Custom accent color and glass opacity
- Corner radius and font scale
- Expanded or collapsed sidebar preference
- Default page and page density
- Home quick links, bookmarks, and recent-sites controls
- Blocked-user management
